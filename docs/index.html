What it does, from opening two accounts at once to carrying on when one runs out of usage.

Made for juggling accounts

The Claude app signs in to one account at a time. Claude Switch gives each account its own window, all open at once, plus the things you need when you work across them.

One window per account

Each profile keeps its own sign-in, chat history, settings and Claude Code memory. Launch from the app, the tray, or your Start menu, Launchpad or app menu.

Usage and reset times

Session and weekly limits for every account as ring gauges, worded like Claude's own panel. 0% means all available.

Weekly · all models  30% · Resets in 1 hr 37 min

Out of usage? Keep going

Hand a Claude Code session to another account with Continue in Personal →. It copies the conversation; the original stays put.

Two accounts, one memory

Unify mode lets profiles share every project's notes, instructions and conversations. When one account runs out, open the other and carry on from exactly where you left off. Sign-ins stay separate.

Picks up where you left off

Start your computer and Claude Switch offers to reopen the profiles you had open last time, or start clean. It can remember your answer.

Keeps Claude up to date

Shows which Claude version each profile runs, and spots the classic trap: a second, forgotten Claude install that stopped updating months ago. One click takes you to the updater, or removes the stale copy.

Fixes sign-in mix-ups

A sign-in link can open in the wrong window and switch its account. Claude Switch spots it, offers Swap names, and recovers sessions that seemed to vanish.

Move to a new computer

Export profiles (sessions, memory, settings) to one password-protected file and import them anywhere. Sign-ins are never exported.

Claude Code in a terminal

Open Claude Code already signed in as Work or Personal, type claude-work in any terminal, or let a project folder pick its profile when you type plain claude.

Set up once, use everywhere

Copy MCP servers from one profile to another, give each profile a colour, rename or duplicate it, use Ctrl+Alt+1–9 shortcuts, and run a Diagnose report when something looks off.

Private by design

No account and no tracking. Its only network request is a daily check for its own updates, which you can turn off. It never reads or sends your sign-in. MIT licensed, so you can read every line.

Install in one step

You need Claude Desktop installed. Then pick your system:

Open PowerShell and paste:

irm https://raw.githubusercontent.com/Ngoni-Sama/claude-switch/main/install.ps1 | iex

Or download the setup or portable zip. Windows 10/11, no admin rights. If Windows shows "protected your PC", choose More info → Run anyway.

Open Terminal and paste:

curl -fsSL https://raw.githubusercontent.com/Ngoni-Sama/claude-switch/main/install.sh | bash

Or download the .dmg (Apple silicon or Intel) and drag it to Applications. macOS 12+. The first time, right-click the app → Open.

Open a terminal and paste:

curl -fsSL https://raw.githubusercontent.com/Ngoni-Sama/claude-switch/main/install.sh | bash

Installs the .deb on Ubuntu/Debian (where Claude Desktop runs on Linux), or a portable copy elsewhere. Also on the releases page.

Questions

Is this made by Anthropic?

No. Claude Switch is an independent open-source project. It doesn't modify Claude; it opens the Claude app you installed with a separate data folder per profile.

Is running two accounts allowed?

Using a work account and a personal account side by side is the main use case. Check your company's rules before moving work into a personal account, and follow Anthropic's terms for your plans.

Does it see my password or sign-in?

No. It never reads, copies or sends sign-in tokens, and exports never include them. Its only network request is a daily check for its own updates, which you can turn off in Settings.

Why do usage numbers sometimes lag?

Claude only logs usage now and then. For live numbers, copy the usage report in a Claude window and Claude Switch updates that tile instantly.

Can I contribute?

Yes, please. See the contributing guide, open a pull request from your branch, and it's merged after review.
